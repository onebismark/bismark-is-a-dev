Colophon & Uses

How these pages are built alongside the hardware, OS environments, and tools used daily.

Site Stack & Delivery

Markup & Style
HTML5 & CSS3
Semantic structure, CSS custom properties, responsive layouts, and dark/light theme support.
Scripting
Vanilla JavaScript
Lightweight client-side interactions with zero heavy runtime dependencies.
Typography
Web Fonts
Syne, Instrument Serif, and JetBrains Mono loaded with font-display swap.
  • Lean payload: Static HTML, CSS, and JS keep initial rendering fast on constrained connections.
  • Versioned assets: Stylesheets and scripts use query versioning (`?v=4`) for cache predictability.

Hardware & Connectivity

Laptops

Phones

Mobile viewport checks, quick captures, and everyday mobile workflows.
Network

Flexible mobile data connectivity across campus and work locations.

OS, Design & Security

Operating Systems

Visual & Photo

Principle: Keep interfaces fast and readable while relying on practical tools that match real workflows.
